# Modern Warfare 2 Takeover

**Minecraft** × Modern Warfare 2 · visual · idea by the team

Bring Modern Warfare 2 into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned Minecraft into Modern Warfare 2: camo soldiers, a Harrier airstrike, and a block-built nuke after ten kills in a row.

## Install

Install Fabric for Minecraft 26.3 with Fabric API, then drop the mod file in your mods folder and start a survival world. Right-click the rifle to fire bursts, get kills in a row for UAV, care packages, a Harrier strike and finally the tactical nuke.
